# Homebrew Tap for labelqueue-cli (labelqueue.com)

Official Homebrew tap for **[labelqueue.com](https://labelqueue.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/labelqueue
brew install labelqueue-cli
```

## Quick Test

```bash
labelqueue-cli --help
```
